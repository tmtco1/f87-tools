    Firmware

    Build a patched firmware here, then flash it with sinowisp on Windows, macOS or Linux. Everything happens in this page; nothing is uploaded.

    1Firmware

    Get the AULA F87 base firmware from tmtco1/f87fw, or open a firmware file, such as a backup of your keyboard.

    Back up your keyboard first

    Read your keyboard's current firmware once and keep the file. Flashing it back restores everything, including your settings and key assignments:

    sinowisp read -d aula-f87 --format bin f87_backup.bin

    You can also open the backup here and patch it: your settings and key assignments are kept.

    Patches

    2Patches

      Empty fields keep the original. Custom effects are built with the scripts in this repository, for example effects/badapple/build.py; the effect slot (6, 9 or 14) is part of the file.

      3Download & flash

      1. Download sinowisp for your system from its releases page (Windows, macOS, Linux) and unpack it.
      2. Plug the keyboard in by USB cable, then run, in the folder with both files: 
        sinowisp write -d aula-f87 --format bin f87_patched.bin
      3. Wait until it says it's done (about 30 seconds) before unplugging. The keyboard restarts by itself.
      Notes per system

      Windows: run sinowisp.exe write … in a terminal opened in that folder.

      macOS: run ./sinowisp write …. If macOS blocks the download, allow it under System Settings → Privacy & Security.

      Linux: run ./sinowisp write …. Without root it needs access to both USB IDs, e.g. this udev rule:

      SUBSYSTEMS=="usb|hidraw", ATTRS{idVendor}=="258a", MODE="0666", TAG+="uaccess"
SUBSYSTEMS=="usb", ATTRS{idVendor}=="0603", ATTRS{idProduct}=="1020", MODE="0666", TAG+="uaccess"

      If flashing stops halfway: the keyboard stays in its bootloader. Run the same command again, or flash your backup.

      Advanced: raw commands and log

      Raw writes go straight to the keyboard. A wrong config or palette write can reset your settings.

      Factory reset restores the lighting the keyboard shipped with: effects, colours, all 5 per-key profiles, light bar and front light. Key assignments and macros are not changed; hold Fn+Esc for 3 seconds on the keyboard to reset those too.
